- ボーナス中にナビどおりベルを取ると、1Gあたりの払い出しは「ベル 49990/65536×7枚 ≒ 5.34枚＋リプレイ ≒ 0.59枚相当＋その他」で約6枚。3枚掛けなら純増 約3枚/Gとなり、公称値と合う（**算出**）。

### 2-2. 停止形（どの絵柄がどう揃うか）

通常時は左リールから押す（上段付近にBARを狙う）。左以外から押すとペナルティの可能性あり。出典: P7 https://pachiseven.jp/machines/4258/cutout/128 ・ 1G https://1geki.jp/slot/okidoki/2/ ・ PT（確定系役の停止形画像）

| 左リールの止まり方 | 考えられる役 | 揃い方 |
|---|---|---|
| 下段BAR | ハズレ（押し順ベル取りこぼし）／リプレイ／共通ベル／確定役 | 共通ベル＝**中段にベルが横一直線**（7枚）。確定役①＝**中段ベルのテンパイハズレ**（左中段・中中段がベル、右はハズレ）など |
| 下段チェリー | チェリー（1枚）／確定チェリー | チェリー＝左リールにチェリー（中・右はANY、1枚）。確定チェリー＝**下段にチェリーが3つ並ぶ「3連チェリー」**（チェリー揃い、またはチェリー＋BAR揃い） |
| 中段チェリー | 中段チェリー | 左中段がチェリー。中・右でBARを狙うと**BARが右下がり**（左上段BAR・中中段BAR・右下段BAR）に揃う |
| 上段スイカ | スイカ（4枚）／確定役 | 中リールは赤7、右リールは赤7・BARの枠外を目安にスイカを狙う。スイカ揃い＝4枚（ライン上ならどこでも。PT配当表では右下がり等も例示）。確定役②＝**スイカのテンパイハズレ**（上段スイカハズレ等） |

- チェリー・スイカに**強弱の区別は無い**（P7 /128）。通常チェリーとは別に「確定チェリー」「中段チェリー」がある。
- チャンス目という分類は無い。代わりに「確定役」（リーチ目）がある。確定役の出目は上記以外にも多数（PT「確定役は当該のリーチ目的存在なため、ほかにも多数あり」）。
- ボーナス中の中押し（中リール上段付近にBAR狙い）: 中段BARが止まれば中段チェリー／確定チェリー／確定役のどれかが確定する。予告音が無いときに中押しで中段ベルが出れば共通ベル確定。1G /2/
- 期待度の順序: ハズレ・リプレイ ＜ チェリー ＜ スイカ ＜ 確定役（リーチ目）。P7 /128、1G /61/
- 通常時の押し順ベル: 左1st正解は存在せず、中1st・右1stの4通り（PT、1G /4/）。押し順ナビはボーナス中のみ。
